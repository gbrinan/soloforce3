작업 예시 · 제안서 준비

자료를 건네고, 무엇을 확인할까요?

아래는 사용 방법을 설명하는 가상 사례입니다. 실제 실행 결과나 완성 품질을 보장하는 예시는 아닙니다.

01 / 준비할 자료

고객 요청과 조사 메모

공유해도 되는 고객 요구사항과 조사 메모를 작업 폴더에 준비합니다. AI가 읽을 자료와 작업 범위를 지정합니다.

02 / 맡길 요청

목차와 근거를 정리해줘

“이 자료로 제안서 목차를 제안해줘. 항목마다 근거 자료를 적고, 자료에 없는 내용은 확인할 질문으로 남겨줘. 원본은 수정하지 마.”

03 / 검토할 결과

목차 · 근거 · 미확인 사항

요청한 항목이 결과에 있는지, 근거가 원본과 맞는지 확인합니다. 빠진 부분은 다시 요청하고 최종 문서는 직접 결정합니다.

개발 작업이라면 변경 계획과 수정 결과를, 지식 정리라면 검토할 후보와 출처를 확인하는 방식으로 시작할 수 있습니다.

실제 AI 작업은 Claude Code가 실행합니다. SoloForce3는 비서에게 요청하고, 직원에게 일을 나누고, 업무와 산출물을 확인하는 화면을 제공합니다.

01 / DELEGATE

역할을 나눠 일하기

비서와 대화하고, 전문 직원에게 작업을 위임합니다. 업무·직원·산출물 화면에서 진행과 결과를 확인합니다.

02 / CONNECT

내 자료를 업무에 연결

로컬 자료를 접수·분류·검색합니다. Drive와 Notion은 별도 연결 후 사용하고, 필요한 자료를 선택합니다.

03 / REVIEW

근거를 남기는 지식 정리

자료에서 정리한 내용을 후보로 모으고, 사람이 확인한 뒤 지식으로 남깁니다. 세부 기능명과 추가 준비물은 이용안내에서 확인하세요.
