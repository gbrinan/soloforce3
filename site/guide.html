01 / PREPARE

먼저 준비해 주세요.

  • Git, Node.js와 npm. 자료 수집까지 쓴다면 기존 검증 환경인 Node 24를 권장합니다. 선언된 Node 범위는 package.json에서 확인합니다.
  • 설치·로그인한 Claude Code CLI. 공식 설치 안내를 따라 준비하고 claude --version으로 확인하세요.
  • Wiki 후보 기능을 쓰려면 Python 3이 필요합니다. 기본 대화부터 시작할 때는 해당 기능을 나중에 설정해도 됩니다.
현재 GitHub Releases에 SoloForce3 설치 파일은 없습니다. 다른 제품의 다운로드 파일을 이 저장소의 설치본으로 안내하지 않습니다.
02 / INSTALL

소스를 받아 실행합니다.

새 설치 폴더에서 진행하세요. 기존 설치가 있다면 설정과 개인 자료를 백업하고 기존 설치 안내를 먼저 확인하세요. Soloforce2 예시 경로를 그대로 적용하지 마세요.

Windows · PowerShell

git clone --branch cycle4/v0 https://github.com/gbrinan/soloforce3.git
cd soloforce3
npm.cmd ci
npm.cmd run build
npm.cmd start

각 명령이 성공한 뒤 다음으로 진행합니다. 기존 실행 방식이 WSL2라면 같은 WSL 환경을 유지하세요. 시스템 실행 정책을 바꾸지 않고 npm.cmd를 사용할 수 있습니다.

macOS · Linux · WSL2

git clone --branch cycle4/v0 https://github.com/gbrinan/soloforce3.git
cd soloforce3
npm ci
npm run build
npm start

서버가 실행되면 브라우저에서 http://localhost:3456을 엽니다. 실행 터미널은 열어 두세요. 위 명령은 백그라운드 서비스나 부팅 시 자동 실행을 등록하지 않습니다.

추가 설정이 필요하면 .env.example을 참고합니다. 기존 .env는 덮어쓰지 말고 필요한 값만 병합하세요.

03 / FIRST TASK

작은 부탁으로 확인하세요.

  1. 초기 화면에서 사용자·비서·직원 이름을 설정합니다. 앱 내부에는 MyCrew 이름이 표시될 수 있습니다.
  2. “새 파일을 만들지 말고 이번 작업의 계획을 먼저 정리해줘”라고 입력합니다.
  3. 업무·직원 화면에서 진행을 확인하고, 산출물이 있으면 열어 검토합니다.
  4. 승인 요청은 대상과 작업 내용을 읽은 뒤 화면의 승인·거부 버튼으로 처리합니다.

Google 로그인과 Drive·Gmail 연결, Claude Code 로그인은 서로 다른 설정입니다. 외부 자료는 해당 계정 연결을 준비한 뒤 사용하세요. 화면별 사용법 →

04 / COST & DATA

사용 전에 알아둘 것.

AI 이용 비용은 별도입니다. Claude 계정의 구독·API 조건이 적용됩니다. 회의 전사·요약과 외부 서비스도 추가 비용이 생길 수 있습니다. 이 페이지는 SoloForce3 판매 요금을 정하거나 무료 이용을 보장하지 않습니다.

로컬 실행과 오프라인 처리는 다릅니다. AI 요청에 담긴 대화·파일 내용은 외부 제공자로 전송될 수 있습니다. 민감한 자료를 연결하기 전에 제공자와 권한 범위를 확인하세요.

권한은 설정에 따라 달라집니다. 처음에는 제한 모드를 사용하세요. 시간 기반 작업은 별도 외부 스케줄러 설정이 필요할 수 있으며, 서버를 켜는 것만으로 예약 실행을 보장하지 않습니다.

FAQ

여기서 막혔나요?

localhost:3456에 연결되지 않아요.

실행 터미널에서 서버가 종료되거나 오류가 나지 않았는지 확인하세요. 다른 포트를 설정했다면 그 주소를 사용합니다. 설치 폴더에서 npm start를 실행하고, 같은 포트를 쓰는 다른 앱은 임의로 종료하지 마세요.

claude 명령을 찾을 수 없어요.

Claude Code 공식 설치 절차와 PATH를 확인하고 터미널을 새로 열어 claude --version을 실행하세요. 설치 경로를 별도로 사용한다면 .env.example의 CLAUDE_PATH 설정을 확인합니다.

설치했는데 화면이 예전 버전이에요.

웹 화면은 빌드 결과를 사용합니다. 해당 소스 폴더에서 npm run build가 성공했는지 확인한 뒤 앱 서버를 다시 시작하세요. 기존 .env와 개인 데이터는 보존합니다.

자료 연결이나 Wiki 기능이 안 돼요.

기본 대화와 별개로 연결 계정·접근 권한·Python 설정을 확인해야 합니다. 자료 수집 안내와 Wiki 안내에서 해당 기능의 조건을 확인하세요.

컴퓨터를 다시 켠 뒤에도 자동 실행되나요?

이 페이지의 소스 설치 명령은 자동 실행을 설정하지 않습니다. 앱 서버를 다시 실행하세요. 반복 예약은 운영 환경에 맞는 외부 스케줄러 설정을 확인해야 합니다.

해결되지 않으면 GitHub에 문제를 남겨 주세요. OS, Node 버전, 실패한 단계와 오류를 적되 키·토큰·개인 자료는 제외하세요.
