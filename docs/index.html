SoloForce (MyCrew)

SoloForce(제품명 MyCrew)는 개인 사용자가 자신의 컴퓨터에서 직접 실행하는 셀프호스팅 AI 비서·에이전트 팀 시스템입니다. 오케스트레이터 비서와 전문 에이전트 팀이 사용자의 지시를 받아 문서 작업, 리서치, 일정·업무 관리를 수행합니다.

주요 기능

  • 자연어 대화 기반 업무 위임 (채팅·터미널·음성 3모드)
  • 전문 에이전트 팀(개발·기획·리서치·지식관리 등) 자동 위임
  • 로컬 파일 기반 지식 코퍼스 적재·검색
  • Google Drive 읽기 전용 연동(선택): 미팅 자료 등 파일 메타데이터 조회

배포 형태

본 소프트웨어는 사용자의 로컬 머신에서 실행되며, 별도의 중앙 서버로 데이터를 전송하지 않습니다. 소스코드: github.com/gbrinan/soloforce2
