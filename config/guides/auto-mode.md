# 자동 / 수동 모드

## 개요
마이크루의 작업 자율성을 조절하는 모드. 자동 모드는 마이크루가 자체 판단으로 진행하고, 수동 모드는 주요 결정마다 사용자 확인을 받는다.

## 자동 모드

- 작업 위임을 자체 판단으로 결정
- 승인 요청 최소화
- 결과만 보고

적합한 상황: 바쁠 때, 자리 비울 때, 마이크루에게 맡기고 싶을 때

## 수동 모드

- 작업 시작 전 확인 요청
- 주요 결정마다 승인 필요
- 단계별 진행 상황 보고

적합한 상황: 중요한 작업, 처음 해보는 작업, 꼼꼼히 확인하고 싶을 때

## 모드 전환 방법

### 헤더 버튼
- 대시보드 헤더의 자동/수동 토글 클릭

### 채팅
- "자동 모드로 바꿔줘" / "알아서 해줘" → 자동 모드
- "수동 모드로 전환해줘" / "하나씩 확인하면서 하자" → 수동 모드

## 부재중 시 자동 전환

- 부재중 모드 ON → 자동으로 자동 모드 전환
- 복귀 시 → 이전 모드로 복원
- 부재중 동안 처리한 내역은 복귀 시 요약 보고

## 사용자 예상 질문 → 답변 포인트

- "자동 모드가 뭐야?" → 마이크루가 알아서 판단하고 작업을 진행하는 모드이다. 승인 요청이 최소화된다.
- "수동 모드가 뭐야?" → 주요 결정마다 사용자에게 확인을 받는 모드이다. 더 꼼꼼하게 관리할 수 있다.
- "모드 어떻게 바꿔?" → 헤더의 토글 버튼 클릭 또는 채팅으로 "자동 모드로 바꿔줘"라고 말하면 된다.
- "부재중이면 자동으로 바뀌어?" → 그렇다. 부재중 모드가 켜지면 자동 모드로 전환되고, 복귀 시 이전 모드로 돌아간다.

## 관련 위치
- 모드 토글: 대시보드 헤더
- 부재중 토글: 대시보드 헤더 (부재중 버튼)
- 승인 동작 변화: `approval.md` 참조
