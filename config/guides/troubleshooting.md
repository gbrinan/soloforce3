# 문제 해결

## 개요
자주 발생하는 문제와 해결 방법 모음. 사용자가 문제를 보고하면 아래 항목을 참조하여 안내한다.

## 서버가 안 뜰 때

**원인 가능성**: 프로세스 미실행, 포트 충돌, 설정 오류

**해결 순서**:
1. 터미널에서 `npm run start`로 서버 실행 확인
2. 포트 충돌 확인 — 이미 사용 중인 포트가 있으면 종료 후 재시작
3. 에러 메시지가 있으면 내용을 확인하여 원인 파악

## 마이크루가 응답 안 할 때

**원인 가능성**: 무거운 작업 처리 중, 세션 문제, 서버 장애

**해결 순서**:
1. 30초~1분 대기 (무거운 작업 처리 중일 수 있음)
2. 중단 버튼 클릭 → 현재 작업 중단 후 새로 시작
3. 세션 리셋 — 채팅창 메뉴에서 "세션 리셋" 선택
4. 위 방법 모두 실패 시 → 서버 재시작

## 화면이 안 바뀔 때

**원인**: 브라우저 캐시 문제일 가능성 높음

**해결**:
- 새로고침: Cmd + R 또는 F5
- 강력 새로고침: Cmd + Shift + R

## 서버 재시작 방법

1. 터미널에서 실행 중인 서버 종료 (Ctrl + C)
2. `npm run start`로 재시작

## 로그 확인 방법

| 로그 종류 | 위치 |
|----------|------|
| 서버 로그 | 터미널 출력 |
| 브라우저 로그 | 개발자 도구 (F12) > Console 탭 |

로그 내용을 복사해서 채팅으로 공유하면 원인 파악에 도움이 된다.

## 사용자 예상 질문 → 답변 포인트

- "서버가 안 돼" → `npm run start`로 실행 확인. 포트 충돌 가능성 체크. 에러 메시지 있으면 공유 요청.
- "마이크루가 멈췄어" → 잠시 기다려보고, 안 되면 중단 버튼 → 세션 리셋 → 서버 재시작 순서로 진행.
- "화면이 이상해" → Cmd+Shift+R로 강력 새로고침 시도.
- "에러가 떠" → 에러 메시지나 스크린샷을 채팅으로 공유하도록 안내. 로그 확인도 병행.
- "어떻게 해야 해?" (막연할 때) → "시스템 상태 점검해줘"라고 마이크루에게 요청하도록 안내.

## 관련 위치
- 서버 실행: 터미널에서 `npm run start`
- 중단 버튼: 채팅창 하단
- 세션 리셋: 채팅창 메뉴
- 브라우저 콘솔: F12 > Console
