# 승인 시스템

## 개요
되돌리기 어렵거나 중요한 결정이 필요한 작업에 대해 마이크루가 사용자에게 승인을 요청하는 시스템.
수동 모드에서는 승인 빈도가 높아진다.

## 승인 요청이 발생하는 경우

- 직원 채용/해고 요청
- 큰 규모의 작업 시작
- 외부 시스템 연동 변경
- 설정 변경 (모드 전환 등)
- 파일 삭제 등 비가역적 작업

## 승인/거부 방법

### 대시보드
1. 사이드 패널 > 승인 대기 탭 확인
2. 요청 내용 확인 후 **승인** 또는 **거부** 클릭

### 채팅
- 마이크루가 채팅으로 승인 요청 시:
  - "승인" 또는 "ㅇㅇ" → 승인
  - "거부" 또는 "ㄴㄴ" → 거부
  - 이유 덧붙이기 가능: "거부, 아직 준비 안 됐어"

## 부재중 모드와 승인

부재중 모드가 켜지면 마이크루가 승인 요청을 자체 판단한다.
- 위험도 낮은 건: 자체 승인 처리
- 위험도 높은 건: 보류 후 복귀 시 알림

### 부재중 모드 켜기/끄기
- 켜기: 헤더 부재중 버튼 클릭 또는 "나 좀 자리 비울게"
- 끄기: 아무 메시지 전송 시 자동 해제 또는 부재중 버튼 재클릭

## 사용자 예상 질문 → 답변 포인트

- "승인 어떻게 해?" → 채팅에서 "승인" 또는 "ㅇㅇ"이라고 답하거나, 사이드 패널 승인 대기 탭에서 버튼 클릭.
- "왜 자꾸 승인을 물어봐?" → 수동 모드에서는 주요 결정마다 확인을 받는다. 자동 모드로 전환하면 줄어든다. → `auto-mode.md` 참조.
- "자리 비울 때 승인은?" → 부재중 모드를 켜면 마이크루가 자체 판단한다. 위험한 건은 보류 후 복귀 시 보고.
- "거부하면 어떻게 돼?" → 해당 작업이 취소된다. 이유를 덧붙이면 마이크루가 참고한다.

## 관련 위치
- 승인 대기 목록: 사이드 패널 > 승인 대기 탭
- 부재중 토글: 대시보드 헤더
- 모드 설정: `auto-mode.md` 참조
