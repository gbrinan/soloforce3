# 대화 기본 기능

## 개요
사용자와 마이크루 간의 채팅 인터페이스 동작 방식. 메시지 전송, 이미지 첨부, 응답 중단, 큐 처리, 대화 기록을 포함한다.

## 메시지 전송

| 동작 | 단축키 |
|------|--------|
| 메시지 전송 | Enter |
| 줄바꿈 (여러 줄 작성) | Cmd + Enter 또는 Shift + Enter |

긴 내용도 한 번에 전송 가능하다. 마이크루가 내용을 파악하여 처리한다.

## 이미지 첨부

- **방법**: 채팅창에 드래그 앤 드롭 또는 붙여넣기(Cmd+V)
- **활용**: 스크린샷, 디자인 시안, 에러 화면 등을 첨부하여 질문/지시 가능

## 큐 처리 (마이크루가 바쁠 때)

마이크루가 다른 작업 처리 중에 메시지를 보내면 큐에 쌓인다.
- 현재 작업 완료 후 순서대로 처리
- 급한 건은 "이거 먼저 해줘"라고 추가 메시지로 우선순위 변경 가능

## 응답 중단 (Abort)

마이크루 응답이 길어지거나 방향이 잘못됐을 때 중단하는 방법:
- 채팅창 하단의 **중단 버튼** 클릭
- 또는 "그만", "멈춰"라고 입력

중단 후 새로운 지시를 내리면 된다.

## 대화 기록

- 이전 대화는 채팅창 스크롤로 확인 가능
- 현재 세션의 대화 맥락은 유지됨
- 세션 리셋 시 맥락 초기화 (작업 기록은 별도 보관)

## 사용자 예상 질문 → 답변 포인트

- "줄바꿈 어떻게 해?" → Cmd+Enter 또는 Shift+Enter로 줄바꿈, Enter는 전송이다.
- "이미지 보내려면?" → 채팅창에 드래그 앤 드롭하거나 Cmd+V로 붙여넣기한다.
- "마이크루가 안 대답해" → 다른 작업 처리 중일 수 있다. 잠시 기다리거나, 중단 버튼을 눌러보라. 그래도 안 되면 `troubleshooting.md` 참조.
- "대화 내용 다 날아갔어" → 세션 리셋 시 맥락이 초기화된다. 작업 기록 자체는 별도 보관되어 있다.

## 관련 위치
- 채팅창: 대시보드 중앙 영역
- 중단 버튼: 채팅창 하단 (마이크루 응답 중에만 표시)
