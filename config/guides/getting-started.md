# 대시보드 구성 및 첫 사용

## 개요
로그인 후 표시되는 대시보드는 마이크루와의 모든 상호작용이 이루어지는 메인 인터페이스이다.
세 영역으로 구성된다.

## 대시보드 레이아웃

### 헤더
- 자동/수동 모드 전환 토글
- 부재중 토글
- 현재 상태 표시

### 채팅창 (중앙)
- 마이크루와의 대화가 이루어지는 메인 영역
- 자유 입력 방식으로 동작

### 사이드 패널 (우측)
- **직원 현황**: 각 직원의 작업 상태 (대기/진행/완료/실패)
- **스케줄**: 등록된 리마인더 및 반복 작업 목록
- **승인 대기**: 승인이 필요한 항목 목록

## 사용자 예상 질문 → 답변 포인트

- "이거 어떻게 써?" → 채팅창에 자유롭게 입력하면 마이크루가 응답한다. "안녕, 마이크루"로 시작해보면 된다.
- "화면 구성이 어떻게 돼?" → 가운데 채팅창, 우측 사이드 패널(직원/스케줄/승인), 상단 헤더(모드 전환) 구조이다.
- "오늘 할 일 보려면?" → 채팅창에 "오늘 브리핑 해줘"라고 입력하면 진행 중 작업, 스케줄 등을 정리해준다.
- "마이크루가 뭘 할 수 있어?" → 대화, 작업 위임, 스케줄 관리, 외부 메시지 등. 상세는 각 가이드 참조.

## 관련 위치
- 대시보드: 로그인 후 메인 페이지
- 모드 전환: 헤더 좌측 토글 → `auto-mode.md` 참조
- 사이드 패널 탭: 직원 현황, 스케줄, 승인 대기
