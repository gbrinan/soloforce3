# 스케줄 / 리마인더

## 개요
마이크루에게 자연어로 리마인더 및 반복 작업을 등록할 수 있다.
시간 표현을 자동 파싱하여 내부 스케줄러에 등록하고, 시간이 되면 알림 또는 작업을 실행한다.

## 리마인더 등록

자연어 입력으로 동작한다:
- "내일 오후 3시에 회의 알려줘"
- "30분 뒤에 알려줘"
- "5월 15일 오전 10시에 보고서 제출 리마인드"

마이크루가 시간을 파싱하여 등록하고, 해당 시점에 채팅으로 알린다.

## 반복 스케줄

정기 반복 작업 등록 가능:
- "매일 아침 9시에 브리핑해줘"
- "평일마다 오후 6시에 일일 보고서 작성해줘"
- "매주 월요일 10시에 주간 회의 준비해줘"
- "매월 1일에 월간 리포트 정리해줘"

## 스케줄 확인/수정/삭제

- **확인**: 사이드 패널 스케줄 탭 또는 "등록된 스케줄 보여줘"
- **수정**: "아침 브리핑 시간을 8시로 바꿔줘"
- **삭제**: "월요일 회의 준비 스케줄 삭제해줘"
- **목록 기반 삭제**: "모든 스케줄 보여주고, 3번 삭제해줘"

## cron 표현식 (고급)

정밀한 스케줄이 필요할 때 cron 표현식 직접 사용 가능:

| cron | 의미 |
|------|------|
| `0 9 * * 1-5` | 평일 매일 오전 9시 |
| `0 18 * * *` | 매일 오후 6시 |
| `0 10 * * 1` | 매주 월요일 오전 10시 |
| `0 0 1 * *` | 매월 1일 자정 |

사용법: "cron `0 9 * * 1-5`로 브리핑 등록해줘"
보통은 자연어로 말하면 마이크루가 cron으로 변환하므로 직접 쓸 일은 드물다.

## 사용자 예상 질문 → 답변 포인트

- "알림 어떻게 등록해?" → 채팅에서 "OO시에 알려줘"라고 말하면 자동 등록된다.
- "반복 스케줄 가능해?" → 가능하다. "매일/매주/매월" 등 자연어로 주기를 말하면 된다.
- "등록한 스케줄 보려면?" → 사이드 패널 스케줄 탭 또는 "등록된 스케줄 보여줘"로 확인.
- "스케줄 삭제하려면?" → "OO 스케줄 삭제해줘"라고 말하면 된다.
- "cron이 뭐야?" → 정밀한 시간 지정을 위한 표현식이다. 보통은 자연어로 충분하다.

## 관련 위치
- 스케줄 목록: 사이드 패널 > 스케줄 탭
- 스케줄 데이터: 내부 스케줄러에서 관리
