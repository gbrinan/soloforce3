# 방법: deep-customer-insight

- id: deep-customer-insight
- name: 심층 고객 인사이트 (심층 조사)
- mode: deep
- when-to-use: 신제품 기획, 포지셔닝 변경, 대규모 캠페인처럼 중대한 의사결정. 비용이 크므로 사용자 확인 후 실행.

## 목적

가상 사용자 인터뷰 → 인식(LMF) → JTBD → 전략/크리에이티브로 이어지는 4-PHASE 프레임워크로,
페르소나 반응 예측을 넘어 실행 가능한 전략과 구체적 아이디어까지 도출한다.

## 시작 전 확인

다음 정보를 확인하고, 없으면 사용자에게 묻거나 합리적으로 가정한 뒤 가정임을 명시한다.

- 제품/서비스명 (필수)
- 제품 설명
- 사이트 URL (있으면 실제 VOC 수집에 사용)
- 기존 리서치 데이터 (있으면 최우선 근거로 사용)
- 타겟 시장 (기본값: 국내)

## PHASE 1 — 가상 사용자 인터뷰

### 1-1. 페르소나 5명 설계

각 페르소나마다 다음을 구체적으로 정의한다:
- 이름, 나이, 구체적 직업
- 배경 (생활 맥락, 관련 경험)
- 쇼핑 행동 (정보 탐색 방식, 구매 결정 습관)
- 핵심 페인포인트
- 성격/태도

극단 사용자(예: 얼리어답터, 극도로 신중한 소비자)와 일반 사용자를 혼합해서 구성한다.
기존 리서치 데이터가 있으면 그것을 근거로 페르소나를 구체화한다.

### 1-2. 그룹 인터뷰 시뮬레이션

가장 대조적인 4명을 뽑아 그룹 인터뷰를 시뮬레이션한다. 다음을 반드시 포함한다:
- 발견 경로 (어떻게 이 제품을 알게 됐는가)
- 좋았던 점의 기능적 이유 + 감정적 이유 (둘 다 필수)
- 혼란/불만과 그때의 감정
- 구매 망설임 요인
- 추천할 때 실제로 쓸 법한 워딩

페르소나 간 의견 충돌과 공감/반박이 반드시 드러나야 한다 — 모두가 같은 의견을 내는 시뮬레이션은 실패로 간주한다.

### 1-3. 페르소나별 요약

각 페르소나에 대해: 핵심 동기 / 주요 망설임 / 전환 트리거를 한 줄씩 정리.

### 1-4. 실제 VOC 교차 검증 (URL이 있는 경우)

사이트 URL이 제공된 경우 WebFetch로 실제 후기·댓글·Q&A를 수집하고, 가상 인터뷰 패턴과 대조한다.
일치하는 지점과 괴리되는 지점을 모두 기록한다. URL이 없으면 이 단계는 생략하고 명시한다.

### 1-5. 공통 패턴 및 우선 타겟 세그먼트 추천

인터뷰 전체를 관통하는 공통 패턴을 정리하고, 우선순위가 가장 높은 타겟 세그먼트를 추천한다.

## PHASE 2 — LMF(Language-Market Fit) 분석

### 2-1. 인식 매핑

페르소나가 자기 말로 제품을 설명하는 표현을 수집/구성한다. 예:
- "~할 때 쓰는 거"
- "~한 사람들한테 좋아"
- "~가 제일 좋은 점"

### 2-2. 3대 질문

1. 알려야 할 대상은 누구인가?
2. 어떤 가치가 어떤 페인포인트를 해결하는가?
3. 가설로 세운 소구점에 페르소나들이 실제로 공감하는가?

### 2-3. 갭 분석

공식 마케팅 메시지 vs 고객이 실제로 쓰는 언어/인식 사이의 차이를 명시적으로 비교한다.

**PHASE 2 핵심 발견 요약 (2~3줄)**: [PHASE 1의 발견과 논리적으로 연결]

## PHASE 3 — JTBD(Jobs-to-be-Done) 매핑

### 3-1. Job Statement

페르소나별로 2~3개씩 "When [상황], I want to [행동], So I can [결과]" 형식의 Job Statement를 작성한다.

### 3-2. Job 분류

각 Job을 Main Job / Related Job / Emotional Job / Social Job으로 분류한다.

### 3-3. 기회 영역 도출

중요도 × 만족도 매트릭스를 구성해 중요도는 높은데 만족도가 낮은 영역(기회 영역)을 찾아낸다.

**PHASE 3 핵심 발견 요약 (2~3줄)**: [PHASE 1-2의 발견과 논리적으로 연결]

## PHASE 4 — 전략 및 크리에이티브

### 4-1. 핵심 전략 문장

"누가, 왜 우리를 사고, 우리는 누구에게 집중하는가"를 담은 전략 문장 1개를 작성한다.

### 4-2. 아이디어 20개

다음 4개 카테고리에 각 5개씩, 총 20개 아이디어를 제시한다:
- 상세페이지 아이디어 5개
- 기획전 아이디어 5개
- 시그니쳐 카피 5개
- 기타 아이디어 5개

각 아이디어는 반드시 다음을 포함한다:
- 제목
- 개요 (1~2문장)
- PHASE 1~3의 어떤 발견에서 이 아이디어가 나왔는지 근거 연결

## 산출물

파일명: `[제품명]_고객인사이트_[날짜].md`

구조:
- PHASE 1: 가상 사용자 인터뷰 전체 내용 + 핵심 발견 요약
- PHASE 2: LMF 분석 전체 내용 + 핵심 발견 요약
- PHASE 3: JTBD 매핑 전체 내용 + 핵심 발견 요약
- PHASE 4: 전략 및 크리에이티브 (아이디어 20개)

PHASE 간 논리 일관성이 필수다 — PHASE 4의 아이디어가 PHASE 1~3에서 나온 근거 없이 등장하면 안 된다.
