# 방법: quick-persona-check

- id: quick-persona-check
- name: 빠른 페르소나 체크 (빠른 조사)
- mode: quick
- when-to-use: 상세페이지·광고 카피·기획전·네이밍 등 일상적인 사용자 대면 산출물에 기본 부착. 별도 요청 없이도 자동 수행되는 기본 모드.

## 목적

무거운 리서치 없이도 "이걸 보면 실제 사용자가 어떻게 반응할까"를 빠르게 점검한다.
산출물 1~2페이지 분량으로, 작업 흐름을 막지 않으면서 인사이트를 더한다.

## 작업 흐름

### 1. 페르소나 3명 설정 (이름/직업/핵심 페인포인트 수준)

- 대상 제품/서비스/카피와 관련된 타겟 고객군에서 대조적인 3명을 뽑는다.
- 각 페르소나는 다음만 간단히 정의한다:
  - 이름 (가상)
  - 직업/생활 맥락 (한 줄)
  - 핵심 페인포인트 (이 산출물과 직접 관련된 것 1개)
- 기존 리서치 데이터나 VOC가 있으면 그것을 근거로 페르소나를 구성한다. 없으면 합리적인 가상 페르소나로 구성하되, 극단적이지 않은 현실적인 인물로 만든다.

### 2. 페르소나별 예상 반응 (긍정/우려/이탈 포인트)

각 페르소나에 대해 다음 세 가지를 짧게 적는다:

- **긍정**: 이 산출물에서 좋아할 만한 지점과 이유
- **우려**: 망설이거나 의문을 가질 지점
- **이탈 포인트**: 결국 이탈하거나 전환하지 않게 만드는 결정적 이유 (있다면)

### 3. 종합 의견 및 개선 제안 top 5

- 세 페르소나의 반응을 종합해 공통 패턴과 상충되는 지점을 짚는다.
- 구체적이고 실행 가능한 개선 제안을 우선순위 순으로 5개 제시한다. 추상적 조언("더 매력적으로 하세요") 금지 — 무엇을 어떻게 바꿀지 명시한다.

## 산출물 형식 (1~2페이지)

```markdown
## 예상 사용자 반응 (빠른 조사)

### 페르소나
1. **[이름]** — [직업/맥락], 페인포인트: [한 줄]
2. **[이름]** — [직업/맥락], 페인포인트: [한 줄]
3. **[이름]** — [직업/맥락], 페인포인트: [한 줄]

### 페르소나별 반응
| 페르소나 | 긍정 | 우려 | 이탈 포인트 |
|---|---|---|---|
| [이름1] | ... | ... | ... |
| [이름2] | ... | ... | ... |
| [이름3] | ... | ... | ... |

### 종합 의견
[2~3문장 요약]

### 개선 제안 Top 5
1. ...
2. ...
3. ...
4. ...
5. ...

※ 본 결과는 가상 페르소나 시뮬레이션입니다. 실제 사용자 검증을 대체하지 않습니다.
```

## 가드레일

- 반드시 마지막에 위 디스클레이머 한 줄을 그대로 포함한다.
- 페르소나는 대조적으로 구성한다 (예: 시간에 쫓기는 직장인 vs 꼼꼼히 비교하는 알뜰 소비자). 서로 비슷한 3명을 만들지 않는다.
- 이 방법은 항상 (a) 예상 반응 + (b) 구체적 의견/제안을 함께 포함해야 한다. 반응 예측만 하고 제안이 빠지면 미완성으로 간주한다.
