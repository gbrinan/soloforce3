# 인사이트 소스 워치리스트 (repo-scout 데일리 순회 대상)

> 사용자와 관리자 에이전트가 관리하는 문서. 관리자에게 "워치리스트에 추가해줘: (URL) (등급)"이라고 하면 여기에 추가됩니다.
> repo-scout는 매일 이 목록을 읽고, 등급에 따라 순회 빈도를 달리합니다.
> - **우선순위**: 매일 확인 (새 포스트/활동을 발굴 보고서 "인사이트 워치" 섹션에 요약)
> - **낮은 등급**: 주 1~2회 로테이션 확인
>
> 확인 방법: X/Threads는 API 미설정이므로 WebSearch(`from:핸들` 검색, nitter 미러 등) 또는
> Gemini 그라운딩 검색으로 최근 활동을 조회. 개별 포스트 URL은 WebFetch로 원문 확인.
> 실패한 소스는 "미수집"으로 정직하게 표기하고 다음 소스로 진행.
