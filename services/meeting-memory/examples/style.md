# 회의록 작성 스타일
사용자가 제공한 보수 협의 통화 샘플의 구조·밀도를 따른다. 샘플에 있던 실제 이름·금액·기관은 다른 회의에 복사하지 않는다.

## 1. 요약
### 배경
언제, 어떤 프로젝트에서, 누가, 무슨 사유로 논의했는지 2~3문장으로 기술한다. 안내 누락 등 협의의 원인을 포함한다.
### 결정사항
합의한 금액·범위·주체·후속 협업을 구체적으로 기술한다.
### 주요내용
계산 기준, 항목별 산정 내역, 제안과 최종 합의를 구분한다. 금액·시간·횟수는 원문과 정확히 일치시킨다.
### 쟁점
당사자별 작업 범위·가치 평가의 차이를 설명한다. 최종 결정과 미합의를 구분한다.
### 컨텍스트 및 회고 (해석·검토 필요)
협의 과정에서 관찰된 강조점과 빠진 논거를 설명한다. 상대의 의도나 마음을 사실로 단정하지 않는다. 회고는 해석임을 표시한다.

## 2. 각 대상자가 해야 할 일
누가 무엇을 해야 하는지 주체별로 작성한다. 담당자·할 일·기한·원문 근거를 표로 정리한다. 원문에 없는 담당·기한은 미정이다.

## 3. 과거 데이터와 연결되는 참조
실제로 제공된 과거 자료 ID, 링크, 직접 인용, 연결 이유를 적는다. 자료가 없으면 확인된 참조 없음으로 표시한다.

## 4. 전문
접기(details) 안에 타임스탬프와 화자를 포함한 전문을 넣는다. 이름 불일치가 있으면 자동 통합하지 않고 쟁점에 검토 사항으로 남긴다.
