# 🧞 mycrew 사용 가이드

> **문서 역할**: 설치가 끝난 최종 사용자를 위한 사용 가이드. 설치는 [README-WINDOWS.md](README-WINDOWS.md)·[README-DISTRIBUTION.md](README-DISTRIBUTION.md), 개발·운영 정보는 [README.md](README.md).

## 이게 뭔가요?

**AI 비서가 당신의 일을 도와주는 시스템입니다.**

- 비서에게 하고 싶은 말을 그냥 하면 됩니다
- 비서가 혼자 처리하거나, 알아서 직원들에게 일을 시킵니다
- 결과는 비서가 정리해서 보고해줍니다

기본 팀: **개발팀장 · 기획팀장 · 감사팀장** 3명. 필요하면 새 직원을 채용할 수도 있어요.

---

## 🚀 시작하기

1. 브라우저에서 **http://localhost:3456** 접속 (포트는 `.env`에서 변경 가능 — 다른 값이면 그 주소로)
2. 처음이면 초기 설정 화면이 나옵니다 → 이름·회사·직원 이름 입력 → 끝!
3. 대화창에서 비서에게 말 걸면 됩니다

---

## 💬 비서와 대화하기

그냥 자연어로 말하면 됩니다. 특별한 명령어 없어요.

**예시:**
- "매일 아침 9시에 브리핑 해줘"
- "이 코드 버그 고쳐줘"
- "시장조사 해줘"
- "지난주 작업 정리해줘"

비서가 직접 하거나 적합한 직원에게 위임합니다. 비서가 바쁠 때 메시지를 보내면 큐에 쌓였다가 순서대로 처리됩니다.

**키보드:** `Enter` 전송 · `Shift+Enter` 줄바꿈

## 🖥️ 화면 구성

가운데 채팅창 + 우측 사이드 패널. **두 영역 경계를 드래그하면 너비 조절** 가능 (조절한 너비는 새로고침해도 유지).

### 헤더 버튼 (왼쪽)
- **재석중 / 부재중** — 자리 상태
- **자동모드 / 수동모드** — 비서가 알아서 진행할지 / 매번 확인받을지
- **권한 단계** — 비서가 쓸 수 있는 범위 (아래 참조)
- **모드(ChatMode/Terminal)** — 평소엔 그냥 두세요

> 모드 버튼은 클릭 시 **"이렇게 바뀝니다" 안내 팝업** + 확인/취소가 뜹니다 — 의도치 않은 전환 방지.

### 헤더 버튼 (오른쪽)
- 📝 **메모장** — 잠깐 적어둘 곳 (대화와 분리)
- **업무** — 사장님이 시킨 일과 진행 상태
- **직원** — 누가 어떤 작업 중인지
- **산출물** — 비서·직원이 만든 파일들
- **친구** — 동료와 주고받은 메시지
- **비용** — 토큰·비용 누적

## 📋 주요 기능

### ✅ 업무 (Task / Todo)
사장님이 시킨 지시 **하나 = 한 Task**. 비서가 직원들에게 쪼개 위임하면 그게 Todo가 됩니다.
- 카드 제목은 사장님 원본 요청을 비서가 짧게 요약한 것
- 완료된 task엔 **📄 보고서** 버튼 — 클릭하면 최종 결과가 팝업으로

### 📂 산출물
직원이 만든 파일들이 쌓입니다.
- `.md`·`.txt` → 클릭하면 미리보기 모달
- `.html` → **새 탭에서 그대로 렌더링** (발표자료 슬라이드 등)
- 그 외 (.pdf·.xlsx·.png 등) → 다운로드

### 🤝 친구 (동료)
다른 회사 비서와 메시지를 주고받습니다. 파일 첨부 OK. 비서끼리 협업해서 일을 처리해요.

### ⏰ 스케줄
리마인더·반복 알림을 자연어로:
- "내일 오후 3시에 회의 알려줘"
- "매주 월요일 주간보고 리마인드"

### 🔒 승인 카드
민감한 작업(권한 밖 파일, 환경설정 변경 등)은 비서가 **채팅 흐름 안에 승인 카드**를 띄웁니다. 카드의 [승인]/[거부] 버튼을 누르면 끝.

> 텍스트로 "ㅇㅇ"/"승인"이라 답해도 처리 안 됩니다 — 반드시 카드 버튼을 눌러야 합니다.

### 🛡️ 권한 단계 (3단계 토글)
헤더 권한 버튼 → 클릭 시 드롭다운에서 선택. 변경 시 효과 모달 + 확인:

| 단계 | 의미 |
|------|------|
| 🔒 **제한** (기본·안전) | 허용된 경로만, 범위 밖·민감 작업은 승인 필요 |
| 🟡 **작업공간** | 프로젝트·mycrew 홈은 승인 없이 자유, 바깥은 차단 |
| 🔴 **무제한** | 시스템 전체 접근, 승인 없음 (신뢰할 때만) |

변경하면 비서가 잠깐 재시작됩니다.

### 🌙 부재중 모드
자리를 비울 때 켜두세요. 비서가 자동 모드로 전환되어 분기점에서 알아서 판단·진행. 복귀해도 자동 모드는 유지됩니다 (수동으로 끄셔야 함).

### 📝 메모장
빠르게 적어둘 곳. 대화와 분리되어 깨끗하게 유지됩니다.

## 🔑 앱 외부 서비스 연동 (선택)

일부 앱은 외부 서비스 API 키가 있어야 전체 기능이 동작합니다. 키가 없어도 앱 자체는 실행되며, 해당 기능만 비활성화되거나 무료 폴백으로 동작합니다.

| 앱 | 필요한 키 | 발급처 | 없을 때 |
|----|----------|--------|---------|
| 책장 | Naver Client ID/Secret 또는 Kakao REST Key | [developers.naver.com](https://developers.naver.com/apps) / [developers.kakao.com](https://developers.kakao.com) | 무료 공개 검색 폴백 (한국어 품질 저하) |
| 디자인 | OpenAI API Key | [platform.openai.com](https://platform.openai.com/api-keys) | 이미지 생성 비활성 |
| 메일 | Resend API Key | [resend.com](https://resend.com) | 발송 비활성 (로그만 기록) |
| 예약 | Supabase URL/Key, Resend API Key | [supabase.com](https://supabase.com) / [resend.com](https://resend.com) | 예약 저장·메일 발송 비활성 |
| 지도 | MapTiler/Google Maps Key (선택) | 각 앱 폴더 `.env.example` 참고 | 무료 지도·검색 폴백 |
| PDF | Stirling-PDF 서버 주소 (선택) | 로컬 Docker (`stirlingtools/stirling-pdf`) | 고급 변환 기능만 비활성 |

**설정 방법 (둘 중 하나):**
1. **대시보드에서**: 설정(⚙️) → **키 볼트**에 키 입력 → 해당 앱 재시작 (비서에게 "○○ 앱 재시작해줘")
2. **파일로 직접**: 각 앱 폴더의 `.env.example`을 `.env.local`로 복사한 뒤 키 입력 (예: `apps/bookshelf/.env.example` → `apps/bookshelf/.env.local`)

> ⚠️ 키는 절대 `.env.example`에 직접 쓰지 마세요 — `.env.local`(또는 루트 `.env`)에만 저장해야 배포/커밋에서 제외됩니다.

## 🌐 외부 접속 (선택)

집 밖에서도 접속하고 싶다면 비서에게 **"외부 접속 설정해줘"** 라고 말하세요. 자동으로 설정해줍니다 (ngrok 무료 또는 SSH 터널 + 도메인).

> 노트북 사용자: 외부 접속이 자주 끊긴다면 비서에게 "맥이 자꾸 자는 것 같아"라고 알려주세요 — 슬립 차단 설정을 안내해줍니다.

## 💡 팁

- 비서가 모르는 건 **"모른다"** 고 합니다 → 그게 정상
- 중요한 건 비서가 기억해둡니다 (위키에 저장)
- **직원 추가/해고**도 비서에게 자연어로 말하면 됩니다
- 작업이 길어지면 비서가 **분기점**(완료/실패/검증)에서만 보고합니다 — 중간 진행은 무음
- 대화 가운데 줄(채팅창과 패널 경계)을 **드래그하면 너비 조정** 가능
